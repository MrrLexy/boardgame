# Game Night Menu

A single-file board game catalog and menu for game night.

**Features:**
- Browse, search, and filter your collection by players, time, and complexity
- Filter by owned / want-to-play / wishlist status
- Cover art and descriptions fetched live from BoardGameGeek
- Random game picker ("Pick for me")
- Print catalog — one card per page with full art and stats
- Dark mode toggle
- Works from any local file or web server — no build step required

Open `index.html` in any modern browser to get started.
